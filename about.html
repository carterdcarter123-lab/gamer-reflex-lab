About

What this site is

A small set of free browser tools for testing gaming reflexes.

Gamer Reflex Lab is a collection of simple, free tools for checking how fast you click, react, and press keys. Nothing to download, no account needed — pick a tool, run the test, see your score.

Why these tools exist

Clicking speed, reaction time, and key-press speed all matter differently depending on what you play. Rather than hunting down separate sites for each one, this is meant to be a single place to check all three, built with the same design so switching between them is quick.

How the tools work

Each test runs entirely in your browser. Nothing you do on this site is uploaded anywhere or tied to an account — your results exist only for the current session and reset when you leave or refresh the page.
