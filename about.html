What this site is

A small set of free browser tools for testing gaming reflexes, plus everyday calculators.

Reflex Drill is a collection of simple, free tools — some for checking how fast you click, react, and press keys, and others for quick everyday calculations like GPA or BMI. Nothing to download, no account needed — pick a tool, use it, see your result.

Why these tools exist

Rather than hunting down separate sites for each thing, this is meant to be a single place to check your reflexes or run a quick calculation, built with the same design so switching between tools is quick and familiar.

How the tools work

Each tool runs entirely in your browser. Nothing you do on this site is uploaded anywhere or tied to an account — your results exist only for the current session and reset when you leave or refresh the page.
